Fresh, server-generated scenarios — no hard-coded question bank in the browser. Pick a level, solve, get an explanation, then move to the next scenario.

How the challenge engine works

🎯 Scenario-based

Questions should look like problems an engineer actually sees: a deploy runs too early, a matrix explodes into 12 jobs, a secret is unavailable, OIDC authentication fails, or a cache unexpectedly misses.

🧠 Explain, don't guess

Every answer has an explanation, the underlying GitHub Actions concept and a “what actually happens?” note. The goal is transferable understanding.

📈 Adaptive later

The browser only renders questions returned by the server-side challenge API. Question generation, source retrieval and validation stay outside the static site.

🤖 AI-ready later

The backend can generate fresh challenges from current technical sources, validate them, store useful analytics and keep every API key server-side — never in the browser.
