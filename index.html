🧪 Challenge Arena

A growing question bank — not one hard-coded quiz. Pick a level, solve, get an explanation, then move to the next scenario.

How the challenge engine works

🎯 Scenario-based

Questions should look like problems an engineer actually sees: a deploy runs too early, a matrix explodes into 12 jobs, a secret is unavailable, OIDC authentication fails, or a cache unexpectedly misses.

🧠 Explain, don't guess

Every answer has an explanation, the underlying GitHub Actions concept and a “what actually happens?” note. The goal is transferable understanding.

📈 Adaptive later

The current engine is client-side and deterministic. Next we can persist progress and generate targeted questions based on weak concepts.

🤖 AI-ready later

A future backend can generate fresh challenges from official documentation and validate submitted YAML. API keys should stay server-side — never in the browser.
