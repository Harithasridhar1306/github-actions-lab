🧪 Challenge: fix the dependency

Don't memorize it. Diagnose it.

INTERMEDIATE · JOBS
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - run: npm run build

  deploy:
    needs: test
    runs-on: ubuntu-latest
    steps:
      - run: ./deploy.sh

What is wrong?

🧠 Why?

The value of needs must reference another job ID. Here, only build exists. If deploy should wait for build, it needs:

deploy:
  needs: build

Try changing the YAML, then explain the execution order in your own words.
